# SAGE brand covers

Approved SAGE social artwork, created October 3, 2026. The main project README
uses the X cover as its banner.

| Export | Dimensions | Intended placement |
| --- | --- | --- |
| [Facebook cover](sage-facebook-cover.png) | 851 × 315 | Facebook Page |
| [LinkedIn cover](sage-linkedin-page-cover.png) | 1512 × 256 | LinkedIn company Page |
| [X cover](sage-twitter-cover.png) | 1500 × 500 | Twitter/X profile |

The built-in image generation tool created the artwork. Original masters are
preserved in `masters/`; generation prompts and export notes are in
`generation-prompts.txt` and `twitter-generation-prompt.txt`. Final exports
were resized or cropped with native `sips`, preserving artwork proportions.

The X cover was refreshed on 2026-10-17 to the current site descriptor,
**"Governed memory for AI agents."** The refreshed export is a deterministic
composition over the same neural hero artwork and SVG wordmark because the
built-in image generation tool was unavailable; the method is recorded in
`twitter-generation-prompt.txt`, and the refreshed 3000 × 1000 master is
`masters/sage-twitter-master-20261017.png`.

The website's SVG wordmark, neural hero and page-specific Open Graph cards are
maintained on the repository's `gh-pages` branch.
